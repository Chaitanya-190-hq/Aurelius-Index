Install & offline

  1. Open this app in Chrome on Android.
  2. Tap the ⋮ menu, then Add to Home screen (or use the Install button here).
  3. Confirm the name — this is where a disguise pays off.
  4. Launch it from the home screen; it opens standalone, without browser chrome.

After the first load the app shell is cached, so it opens and works without a connection.

Privacy

Everything you write is stored in IndexedDB in this browser, on this device. Nothing is uploaded, and the app makes no analytics or tracking requests. It does not sync: another phone, another browser, or a cleared browser profile will not have your data. Export a backup before clearing site data.

  • No account, no email, no password.
  • No third-party scripts, fonts or images.
  • Network is used only to fetch the app files themselves.
